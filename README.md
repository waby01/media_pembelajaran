# Modulku AI - Media Pembelajaran Interaktif (Bab: Bunyi Apa? - Kelas 1 SD)

Aplikasi media pembelajaran berbasis web interaktif untuk mata pelajaran Bahasa Indonesia Kelas 1 SD dengan fokus materi capaian pembelajaran bab "Bunyi Apa?".

## 🚀 Fitur Utama
1. **Modul Interaktif & Voice Pembaca:** Materi dikelompokkan dalam kartu visual interaktif dengan pembaca suara Bahasa Indonesia (`id-ID`) yang alami.
2. **25 Bank Soal & Randomized Quiz:** Kuis secara otomatis mengacak **10 soal baru** dari 25 bank soal di setiap sesi pengerjaan.
3. **Tanya Miko (AI Learning Companion):** Chatbot AI Gemini yang terhubung ke `database.json` pengetahuan seputar jenis, sifat, dan sumber bunyi.

## 📁 Struktur File
- `index.html`: Kerangka UI web.
- `style.css`: Animasi visual dan kustomisasi style.
- `script.js`: Logika acak kuis, pembaca suara, dan AI Gemini.
- `database.json`: Tempat penyimpanan 25 bank soal, materi detail, dan knowledge AI.
- `README.md`: Dokumentasi proyek.
